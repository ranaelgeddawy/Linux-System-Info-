# Linux System Info Automator 🐧

A lightweight Bash script designed for Linux environments to quickly gather, format, and display comprehensive system and hardware information.

---

## 🚀 Features

- **System Overview:** Displays OS name, kernel version, and architecture.
- **Hardware Metrics:** Checks CPU details, total and free RAM usage, and disk space.
- **Network Status:** Gathers active IP addresses and network interface status.
- **Automation Ready:** Easy to execute and integrate into daily administrative tasks.

---

## ⚙️ Prerequisites

- A Linux-based operating system (Tested on Kali Linux / Ubuntu).
- Bash shell.
